# Anodyne

## Voice Processing Highlights

- **AI-Powered Noise & Reverb Removal** — Eliminates background noise and room tone while preserving the natural character of the voice.
- **Frequency Recovery** — Restores missing high- and low-frequency detail lost to poor mic placement or difficult recording conditions.
- **Intelligent Leveling & Dynamics** — Smooths volume differences using LUFS-based automation instead of heavy-handed compression.
- **Breath, Sibilance & Gate Control** — Detects and cleans pauses, breaths, and harsh consonants with transparent, fully editable processing.
- **Adaptive Voice Processing** — Performs consistently across vocals, dialogue, podcasts, and voice-over by adapting to each recording.
